# Ping Pong
Um joguinho de Ping Pong feito com HTML, CSS e JavaScript.

Fiz esse projeto como uma forma de praticar JavaScript e brincar um pouco com Canvas. A ideia era fazer algo pequeno, simples e que realmente desse pra jogar.

## Como jogar

Você controla a raquete da esquerda.

- W → subir
- S → descer

A bola vai ficando mais rápida conforme as rebatidas acontecem, então é melhor não dormir no ponto. Literalmente.

## Dificuldades

O jogo tem três opções:

- Fácil
- Normal
- Difícil

Cada uma muda a velocidade da CPU.

## Como funciona

- Cada set vai até 11 pontos
- É necessário ganhar por 2 pontos de diferença
- A partida é melhor de 3 sets
- Quem ganhar 2 sets primeiro vence a partida

## Tecnologias

- HTML
- CSS
- JavaScript
- Canvas API

Não usei framework nem biblioteca externa. É basicamente HTML, CSS e JavaScript na raça.
